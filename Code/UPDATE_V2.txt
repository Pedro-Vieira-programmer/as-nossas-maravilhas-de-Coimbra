OPÇÃO 1: No Telemóvel (RECOMENDADO)
  1. Copie o ficheiro index.html para o telemóvel
  2. Abra direto no navegador
  3. Ocupa a tela toda, sem moldura ✓

OPÇÃO 2: No Browser Desktop (Teste)
  1. Abra index.html
  2. Pressione F12 (DevTools)
  3. Ctrl+Shift+M (Device Toggle)
  4. Escolha um dispositivo mobile
  5. Veja como fica no telemóvel

OPÇÃO 3: Servidor Local
  1. cd Code
  2. python -m http.server 8000
  3. Acesse http://localhost:8000
