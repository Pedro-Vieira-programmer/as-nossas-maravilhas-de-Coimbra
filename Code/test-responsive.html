Como Testar

1. Chrome DevTools (Recomendado):

  • Abra index.html
  • Pressione F12 para abrir DevTools
  • Clique em Device Toggle (Ctrl+Shift+M)
  • Teste diferentes dispositivos

2. Servidor Local:

  • cd na pasta Code/
  • Execute: python -m http.server 8000
  • Acesse: http://localhost:8000

3. Navegador Web:

  • Abra index.html diretamente
  • Redimensione o navegador
  • Veja o layout adaptar-se responsivamente
